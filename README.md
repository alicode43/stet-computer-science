> **Official CBT Exam Simulator for Bihar Secondary Teacher Eligibility Test (STET) Paper-II (Senior Secondary Classes 11–12 / PGT Computer Science)** conducted by the Bihar School Examination Board (BSEB).

---

## 🎯 Features of the Free Test Series

- **100% Free & Open-Access**: Zero subscription, zero paywalls, no login required.
- **899+ Authentic PYQs**: Real questions from official 2023, 2024, and 2025 examination shifts.
- **Realistic CBT Interface**: Official 150-minute exam countdown timer, question status palette (Answered, Marked for Review, Not Visited), and instantaneous score computation.
- **13 Topic-Wise Modules**: Practice focused drills for individual subjects (Python, Data Structures, DBMS, Operating Systems, Computer Networks, Digital Electronics, and more).
- **Exam Mode vs. Practice Mode**: Choose between strict exam simulation or instant-feedback practice with deep explanations for answers and distractors.
- **Dark & Light Mode**: Built for long study sessions with eye comfort.

## 📋 Bihar STET Paper-II Exam Pattern

| Parameter | Details |
|---|---|
| **Exam Level** | Higher Secondary / PGT (Classes 11 & 12) |
| **Conducting Body** | Bihar School Examination Board (BSEB) |
| **Total Questions** | 150 MCQs |
| **Total Marks** | 150 Marks |
| **Duration** | 150 Minutes (2.5 Hours) |
| **Marking Scheme** | +1 for Correct, **0 for Incorrect (NO Negative Marking)** |
| **Section A** | 100 Marks (Subject Specific: Computer Science) |
| **Section B** | 50 Marks (Art of Teaching: 30 Marks, Other Skills: 20 Marks) |

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/alicode43/stet-computer-science.git

# Navigate into the project
cd stet-computer-science

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to access the CBT simulator.
